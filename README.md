# hypertracker

```
npm install hypertracker
```

## Usage

```js
const { HyperTracker, HyperTrackerClient, HyperTrackerMultiClient } = require('hypertracker')
```

Or import only what you need:

```js
const HyperTracker = require('hypertracker/server')
const HyperTrackerClient = require('hypertracker/client')
const HyperTrackerMultiClient = require('hypertracker/multiclient')
```
